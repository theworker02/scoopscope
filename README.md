# scoopscope

Scoop digests and scope fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/scoopscope/

## Install / run

```bash
git clone https://github.com/theworker02/scoopscope.git
cd scoopscope
node src/cli.js
node --test
```
